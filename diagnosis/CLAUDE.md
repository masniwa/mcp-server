# Claude Code — Burp MCPによる診断

本書は、診断用プロジェクト直下へ配置するClaude Code用の読込入口である。共通の行動ルールは次のAGENTS.mdへ集約する。同書の指示に従い、同じディレクトリーのspec.mdも作業開始前に全文読む。

@AGENTS.md

## 使用前の確認

- 作業開始前に、両文書が最後まで読み込まれていることを確認する。`/context`で読込状況を確認できる環境では、参照先も確認する。参照先が欠落・省略・読取不可なら、未読のまま診断を始めない。
- 別PCでは、本書・`AGENTS.md`・`spec.md`・`read.me`を診断用プロジェクト直下へ配置し、そのディレクトリーをClaude Codeの作業場所として開く。作業用`temp`は同じプロジェクト直下とし、基準と整理方法はAGENTS.md第11章に従う。
- 初回の導入・接続設定は同じ場所の`read.me`に従う。MCP登録や文書読み込みの成功だけで診断準備完了とはせず、今回の正常通信の記録と必要な構成の検証まで進める。
- `/mcp`等でBurp MCP Serverへの接続と利用可能なToolを確認し、個別操作前にそのToolの入力スキーマとDescriptionを読む。Tool名の接続先プレフィックスや、Codex専用の呼出形式を固定しない。本書を配置しただけではMCP接続は設定されない。
- 管理方式の診断は通常-reのREVIEWと`diagnostic_job`を使い、動的なMacro・Rule・CPHの作成と検証を維持する。従来版の直接操作と区別し、承認、検証証拠、設定復元、診断中の再ロード禁止はAGENTS.mdとspec.md第2.2章の共通手順に従う。
- Computer Useと継続実行の能力・権限は、実際のClaude Code環境で確認する。文書を読み込んだことだけで、Burp UIの操作やターン終了後の自動継続が可能になったとは扱わない。利用できない場合の扱いは診断用spec.md第2章・第6章に従う。

参照文書は診断範囲や操作権限を付与するものではない。ユーザーの診断依頼と確認済みの許可範囲に従う。
